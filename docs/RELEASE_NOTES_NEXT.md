# Next and Public Release / 下一版与公开版本

## Next release / 下一版

**Magpie Experimental v0.6.13** 当前处于本地发布准备阶段（本地候选，尚未公开上传），基于公开版 **v0.6.12** 与 0.6.13 Beta 3 功能收口。主要包含 DLSSNR 自适应分辨率与 SDR NVIDIA 光流同步隔帧改进、DLSSNR 前端复制与查询减负、FSR 2／FSR 3／XeSS／RTX Video GPU 同步与恢复、内联参数编译修复，以及侧栏档案上下移、繁体中文效果目录、配置上限保护、开机任务权限收紧与 RTSS 校验。

**Magpie Experimental v0.6.13** is currently a local release candidate in preparation (not yet published), built on **v0.6.12** with the 0.6.13 Beta 3 feature set. Highlights include DLSSNR adaptive resolution and SDR NVIDIA Optical Flow synchronous alternating-frame improvements, DLSSNR frontend copy/query overhead reduction, FSR 2/FSR 3/XeSS/RTX Video GPU sync and recovery, inline-parameter compilation fixes, sidebar profile reordering, Traditional Chinese catalog updates, config size-limit protection, auto-start task hardening, and RTSS verification.

[Magpie Experimental v0.6.12](https://github.com/SAOG0721/Magpie/releases/tag/v0.6.12-experimental) was published on 2026-11-06 as a Pre-release. It introduces OKLab Image Adjustment, DLSSNR model presets and adaptive resolution, Every Frame / Alternating Frames processing, live parameter overlay zoom (Ctrl + Mouse Wheel), and capture/VRR presentation improvements.
