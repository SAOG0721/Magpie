# 下一版与公开版本 / Next and public release

## 0.6.11 — 待审核 / Awaiting review

本版增加性能分析浮窗与捕获／输出图表、DLSS SR／FG 模型预设、DLSSNR 抗闪烁响应时间，补齐 XeSS 输出帧间隔，更新运行库并改进暂停截图与命名。完整功能与安装说明见[中英双语 Release Notes](RELEASE_NOTES_v0.6.11-experimental.md)。[GitHub Draft](https://github.com/SAOG0721/Magpie/releases/tag/untagged-c23927d0f93baaa5e319) 已创建，三个附件已上传并核验，保持 Draft + Pre-release，等待维护者审核。

This version adds a resizable profiler with capture/output charts, XeSS output intervals, DLSS SR/FG model presets and DLSSNR anti-flicker response time, updates runtimes, and improves paused screenshots and filenames. See the [complete bilingual release notes](RELEASE_NOTES_v0.6.11-experimental.md). The [GitHub Draft](https://github.com/SAOG0721/Magpie/releases/tag/untagged-c23927d0f93baaa5e319) and its three verified assets are ready for maintainer review. It remains an unpublished Draft + Pre-release.
