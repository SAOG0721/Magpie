## 0.6.11 — 待审核 / Awaiting review

本版增加 DLSS SR／FG 模型预设、DLSSNR 抗闪烁响应时间，更新 SM86／FG 运行库和默认社区 DLSSNR，并改进暂停截图与截图命名。完整变化、安装步骤与限制见[中英双语 Release Notes](RELEASE_NOTES_v0.6.11-experimental.md)。按维护者授权准备完整附件并同步 GitHub；Release 保持 Draft + Pre-release，等待人工检查后另行决定发布。

This version adds DLSS SR/FG model presets and DLSSNR anti-flicker response time, updates SM86/FG and the default community DLSSNR runtime, and improves paused screenshots and file naming. See the [complete bilingual release notes](RELEASE_NOTES_v0.6.11-experimental.md). Source and distribution assets are prepared for review; the release remains Draft + Pre-release until separately approved for publication.
