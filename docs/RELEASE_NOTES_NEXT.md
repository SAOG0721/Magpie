# 下一版与公开版本 / Next and public release

## 0.6.11 — 待审核 / Awaiting review

本版增加性能分析浮窗与捕获／输出图表、DLSS SR／FG 模型预设、DLSSNR 抗闪烁响应时间，补齐 XeSS 输出帧间隔，更新运行库并改进暂停截图与命名。完整变化、安装步骤与限制见[中英双语 Release Notes](RELEASE_NOTES_v0.6.11-experimental.md)。本轮修订仅准备本地文件，在创建或更新 GitHub Draft 前停止，等待维护者检查。

This version adds a resizable profiler with capture/output charts, XeSS output intervals, DLSS SR/FG model presets and DLSSNR anti-flicker response time, updates runtimes, and improves paused screenshots and filenames. See the [complete bilingual release notes](RELEASE_NOTES_v0.6.11-experimental.md). This revision prepares local files only and stops before creating or updating a GitHub Draft for maintainer review.
