# DLSSNR Multi Pass（0.6.12 Beta 5）

参数按“细节控制｜残差进阶｜性能进阶｜DLSSNR · Pass 1｜启用的 Pass 2／3”分组。两项进阶开关默认关闭，收起保留参数数值与效果。设置页和运行浮层采用单页多列布局，横向和纵向均不滚动；原控件与字号保留，窄浮层按内容自动扩宽。

在 `DLSSNR · Pass 1` 的“UI 修正”下方，选择 `Multi Pass` 的 `1 / 2 / 3`。默认是 1，最多是 3。2 次显示 Pass 2，3 次再显示 Pass 3。参数说明不常驻显示，鼠标停留于名称时查看简短用途说明。

新增层使用 DLSSNR 默认参数。减少次数只隐藏并停用后面的层，保留它们的设置，再次增加次数会恢复。恢复某个参数的默认值仅影响该层。Multi Pass 使用下拉框直接选择次数。

Pass 1 中 `Multi Pass` 后是“抗闪烁”下拉框，默认“无”。

| 选项 | 作用 |
| --- | --- |
| 无 | 保持当前 NR 输出，不分配额外抗闪烁历史 |
| 静态累积 | 在原输入颜色稳定的区域累积修正，运动或颜色变化处使用当前结果 |
| 光流累积 | 先用光流对齐历史，再验证原输入颜色并累积修正 |
| 光流累积+ | 光流验证后，分别平滑修正的持续性与出现时的幅度，缓和修正反复出现／消失 |
| 低频时域重建 | 半分辨率残差观察与原分辨率历史联合重建；保留当前高频差分，主要稳定低频修正 |

单层和多层均稳定 `最终输出 − DLSSNR 原输入` 的总修正，再加回原输入。处理位于统一 Residual 控制、残差升采样与原图叠回之后，不把累积结果送回下一帧 NGX。低频时域重建继续在输出端提取低分辨率总差分并做联合重建。

光流累积、光流累积+、低频时域重建要求先选择 AMDOF 或 NVOF。将光流改为“无”时，这三种抗闪烁模式自动回退到静态累积，历史帧重投影同时改为原位复用。运行中光流失效会清除不再匹配的历史。

切换“无 / 静态累积 / 光流累积 / 光流累积+ / 低频时域重建”沿用自动重启流程。即时修改活动 NR 或 Residual 参数、上游输入修订、捕获重置、资源变化或超过 250 ms 的帧间隔都会使旧历史失效。Residual 更新复用 NR 输出，只重做出口处理；隐藏层设置不扰动活动历史。同一个捕获帧不重复累积。静态累积、光流累积和低频时域重建的幅度时间常数暂定 80 ms，约相当于 60 次真实更新/秒时 0.812 的基础历史权重，再按输入匹配质量降低。

各抗闪烁选项互斥，旧配置保留原选择；没有已保存的选择时默认关闭。恢复默认值会关闭抗闪烁。

光流累积+的持续性采用 60 ms 出现、180 ms 消退；出现时的条件幅度采用 80 ms 更新，缺失观察不把零值混入该幅度。输入变化或历史失效立即取消旧修正。弱于阈值的修正可能被削弱，反复出现的修正可能比普通均值保留得更强；它不保证时间均值不变。

低频时域重建固定从最终有符号差分提取宽高各约一半的观察，不随“输入分辨率”百分比改变。低分辨率差分用原图颜色引导升采样，在同一输出 dispatch 中与经过验证的原分辨率历史混合；高频补偿使用当前帧，以保住细线和孤立修正。未加入 jitter，也不从 NGX 内部直接取低分辨率纹理，该抗闪烁路线本身不会减少模型推理或出口缩放成本；高频补偿中的闪烁仍可能存在。低频时域重建相比另外三个抗闪烁选项 额外增加两张半分辨率 RGBA16F 纹理和一次提取 dispatch。

算法公式、阈值、内存和验收范围见[技术路线文档第 14 节](../design/20260914-dlssnr-temporal-stabilization-routes.md#14-068-local-扩展实施f--g)。

| 每层独立参数 | 默认值 | 范围 |
| --- | --- | --- |
| NR Style | 0 | 0～2 |
| NR Intensity | 1 | 0～2 |
| Local Tone Strength | 1 | 0～2 |
| Local Structure Strength | 1 | 0～2 |
| Skin Structure Strength | 0 | 0～2 |
| Automatic Mask | 关闭 | 开 / 关 |
| NR UI Correction | 关闭 | 开 / 关 |

模型预设、输入分辨率和光流设置由整条链共用。SDR 始终使用残差重建，各层在同一推理尺寸串联；出口以最后输出减最初输入提取总残差，统一应用整体、明度／色度及明暗细节修正，再升采样并加回原尺寸输入。输入比例为 100% 时仍可调整残差。效果器整体输入与输出分辨率相同；光流沿用共享捕获帧服务，不为中间画面重新估算。HDR 仍遵循现有受限路径。

残差进阶包含色相保护、色度保护、暗部／亮部保护、过度修正抑制、低频／高频强度和诊断视图。色度保护范围为 0～1、步进 0.05，缩小 Oklab 的颜色残差而保留明暗残差；0 不保护，1 在残差处理阶段保留原图颜色。原中性／肤色保护及分区色度已移除，旧键清理后新保护默认 0。

性能进阶仅提供逐帧和隔帧。“NR 更新间隔”在隔帧模式下显示，可选“每 2 帧／每 3 帧／每 4 帧”，默认每 2 帧；仅接受的新捕获帧计数，重复刷新、重绘和生成帧不推进周期。

| 模式 | 更新与历史处理 |
| --- | --- |
| 逐帧 | 每个新捕获帧完整计算，输出当前画面 |
| 隔帧 | 按所选间隔更新完整 NR，当前画面持续更新并连续复用历史增强；首次、硬重置、没有可用历史或整条运动映射无法构建时，按相同规格重建 |

隔帧固定使用连续复用，正常周期不会运行轻量 NR，也不因软失配增加完整 NR。连续复用保留真实源年龄和完整 NR 观察时钟；接受局部拖影或增强减弱，复用不会生成新的完整 NR 观察。

旧配置中的异步逐帧自动回退为逐帧，异步隔帧自动回退为隔帧；保留已保存的有效 NR 更新间隔、模型预设、输入分辨率比例。更新间隔缺失或无效时使用每 2 帧。“帧率与刷新”中的独立 Async 节奏继续保留，设置入口与使用方式见[帧率与刷新指南](../../FRAME_SYNC_GUIDE.md)。

运行中的参数面板在同页保留分组标题、名称悬停提示、次数和各层设置。改变次数沿用现有自动重启流程重建处理链；各层七个独立参数沿用即时应用规则。SDR 的共享细节参数可实时修改；HDR 下原有分辨率调整和残差限制继续适用。

多次处理会增加资源使用量，具体画面、耗时和显存开销需要实机对比。

## 配置与资源

效果列表中仍使用一个 DLSSNR 条目，Multi Pass 次数与各层参数一同保存、复制和导入导出。没有已保存的次数时默认使用 1 次；缺失的 Pass 2／3 参数使用各自默认值，不复制 Pass 1。

残差进阶与性能进阶分别保存显示状态，不因收起而重置算法参数。旧时效选择不再影响运行或重建；关闭光流时同步保存兼容的抗闪烁和复用选项。

每层拥有独立 NGX 特征、参数、时序历史和可缓存输出。整链共用队列、围栏、命令环、引导、缩放与残差资源，层间直接传递 D3D12 输出；只在入口和出口进行 D3D11 / D3D12 同步。重建时先排空队列，再释放旧链。SDK 初始化、关闭和兼容钩子仍由共享会话持有，最后一个特征释放后才关闭。

即时改变某一层 NR 参数时，只重算该层及后续层，并保留前面仍有效的缓存。纯 Residual 更新不会使任何层的 NR 结果失效。多层初始化、尺寸重建或任意层评估失败时拒绝完整处理链；默认单层保留原有不可用回退行为。
