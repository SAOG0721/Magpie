# 性能分析浮窗：默认精简、图表二级展开与尺寸调整

2026-10-23。用户已授权目标模式实施及验证；沿用本会话已有的备份覆盖 0.6.11 授权，GitHub 发布继续取消，暂不使用 Computer Use。

## 设计

1. 保留硬件、捕获方式及帧率文字。默认展开“用时”，优先显示原有各效果器／通道明细、耗时占比和总耗时；单效果继续使用原有单效果合计形式。
2. 在用时明细及总计之后增加二级“图表”节点，默认折叠。用户点击后才绘制“帧率、帧间隔、效果器耗时”三图，折叠时不读取、布局或绘制图表。已开启分析器的固定容量历史继续采样，展开后可立即回看最近 10 秒。图表展开状态只在当前缩放会话保留，不新增全局设置。
3. 不可用／部分统计说明仍对耗时明细生效，不因图表折叠而隐藏必要说明。缺测与有效零、帧率来源及统计范围保持已有语义。
4. 参考实时参数浮窗：使用相同的右下角缩放握柄样式、视口边界约束、逻辑像素尺寸保存和边缘锚点恢复。初始 310×360，最小 310×220 逻辑像素；小视口优先保证窗口可见，最大尺寸为可用视口减去 16 逻辑像素。图表展开／折叠不强制改变用户选定的尺寸，内容不足时纵向滚动。
5. 复用 `OverlayWindowOption.width/height`，旧配置的零值使用默认大小，无配置迁移。仅用户移动／缩放时记住布局，松开鼠标后沿用现有保存回调；DPI／视口临时缩小时不覆盖偏好尺寸，恢复后重用原尺寸。
